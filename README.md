# Gestionvig — Gestión de Vigilantes · PYSCPR

**Responsable:** Coordinación de Protección y Seguridad.

## Para qué sirve

App HTML para gestionar vigilantes por albergue: carga de personal y vacaciones desde Excel, novedades (incapacidades, faltas, permisos), asignaciones de turno y exportación.

## Archivo principal en este repo

- `GESTION VIGILANTES (1).html` — versión publicada en GitHub (rama `main`).

## Quién lo usa

Coordinación de Protección y Seguridad / quien administra turnos y novedades de vigilantes.

## Cómo se usa

Abrir el HTML en el navegador con conexión a internet. Cargar Excel de vigilantes y vacaciones; registrar novedades y asignaciones; exportar según necesidad.

## Dónde se guardan los datos y cómo respaldar

Datos de configuración (vigilantes, vacaciones) y colecciones de novedades/asignaciones en la nube (Firebase). Exportar Excel antes de operaciones de borrado. **No** subir claves de Firebase a este README ni a issues públicos.
